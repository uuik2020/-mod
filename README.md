# AI雇工 (AI Hireling)

> 《星露谷物语》SMAPI Mod — 一个会自己打工的像素小农夫

进农场，农舍门外站着一位戴草帽的小农夫。跟他对话就能雇佣——**第一次雇佣免费，前两天打工也不要钱，之后按天收费**。
雇佣之后，收获、浇水、播种、翻地、采集、砍树、打怪、挖矿、钓鱼、清理农场杂草树枝……他全包了。
他头顶会实时告诉你他正在干什么，所有参数都能在游戏内配置菜单里调。

## ✨ 功能特性

- **🤖 全自动打工**：收获成熟作物 → 给干渴的作物浇水 → 播种 → 开垦新地 → 捡掉落物和机器成品 → 砍树 → 打怪 → 矿洞挖矿 → 水边钓鱼
- **🧹 农场清理**：一键清理农场上的杂草、枯死作物、树枝、石头、树桩
- **🎒 背包满了会自己去找箱子（v2.7.1）**：背包一满，只要 12 格内摆着箱子，他会自己走过去把东西塞进去（头顶显示「背包满了，去塞箱子」），不用再对话选一次；箱子满了才回头找你
- **🎒 背包满了会来找你**：背包装到「背包容量」组数就自动跑到你面前说一句——「老板，我背包塞满啦（12 组），实在装不下新的了。这些是直接交给你，还是我找个箱子放进去？」三个选项：都给你 / 塞进 12 格内最近的箱子 / 先背着（2 小时后再提醒）；容量和开关都能在设置里调
- **🎒 AI 背包**：清出来的树枝（294）、石头（390）、树桩木头（388）先进他背包，对话里「领取物品」免费全给你；没领走的存档不丢，倒下时掉在脚边
- **🧭 会绕路的寻路**：直线被挡时自动在网格上找路绕过去（BFS 800 节点 / ±22 格）；**卡住 2.5 秒就朝目标挪一小步再继续走**，墙角、门口、栅栏夹缝都不会再卡十几秒；实在到不了的目标拉黑 1 分钟换个活干
- **🏷️ 头顶实时状态**：干活时头顶是一条深色**状态胶囊**（「等鱼上钩 4.2s」「砍树中」「背包满了，去找你」…钓鱼时胶囊里还带进度条），下面一行名字，脚下合并显示「（模式）背包 N」——分行排布，不会糊成一团
- **🎣 钓鱼有完整动画**：走到岸边 → 甩竿（竿子从后上方挥到指向水面、浮漂抛物线飞出去）→ 等鱼上钩（浮漂抖动 + 水面涟漪 + 头顶倒计时和进度条）→ 咬钩（浮漂下沉 + 水花）→ 收竿，全程能看出来他在钓鱼而不是卡住
- **🎣 钓鱼走原版判定**：钓什么由游戏自己决定（当前地图 / 季节 / 天气 / 水深 / 钓鱼等级），和玩家亲手钓一样；配置「可钓鱼类列表」留空即可，填了不存在的 ID 会自动剔除，绝不会再钓出「错误物品（754）」
- **🎣 钓鱼不是白来的（v2.4.0）**：和原版一样**要鱼竿**（放你背包里就行，他借你的用）、**每竿扣 1 个鱼饵**（先用他自己背的，再用你的；没饵也能钓，但咬钩时间翻倍）、**每竿扣体力**（8 - 钓鱼等级×0.1）。体力睡一觉回满，待命/跟随站着也慢慢回；没竿或没体力他会直接说「给我一根鱼竿」「我累了」然后跟着你，不再空手变鱼
- **⛏️ 挖矿也要花东西（v2.5.0）**：和钓鱼一样**要镐子**（放你背包里就行）、**每敲一下扣体力**（2 - 挖矿等级×0.1，同原版镐子公式）；农场清理里的石头同样算，没镐子就先不清石头。没工具他会说「我手上没镐子」
- **🎒 能直接打开他的背包（v2.5.0）**：对话 →「打开他的背包（给东西 / 取东西）」，像开箱子一样把鱼饵、食物塞给他，也能把他捡的东西直接拿走；工具会还给玩家（他只是借用）
- **🌿 会被草和作物挡住（v2.6.5）**：AI 的身体画在**和玩家同一层**（Harmony 挂进原版 `drawFarmers` 之后），走进草地、作物地、树后面时会被草叶和树冠盖住，每张贴图只画一次不会糊成一团；同时**上半身会在草丛/作物里露出来**（腿埋在草里），但背后是树、果树、灌木时会老老实实被挡住，不会穿模；**他躲到树后面时那棵树会像玩家在后面一样虚化成半透明**，一眼就能看到他。在「设置 → 显示效果」里可以关掉
- **🖥️ 控制台彩色 + 图标（v2.6.2）**：SMAPI 那个黑窗口里的日志不再是清一色的白字——`◆` 信息（青）、`▶` 步骤（蓝）、`√` 成功（绿）、`▲` 警告（黄）、`×` 错误（红）、`★` 重点（金），`[钓鱼]` `[寻路]` 这类标签单独高亮；启动时是一块带分隔线的横幅。颜色和图标都能在「设置 → 控制台显示」里单独关掉
- **🎮 9 种工作模式**：自动 / 跟随 / 农场 / 战斗 / 农场清理 / **砍树** / 挖矿 / 钓鱼 / 待命，随时对话切换（「砍树」是 2.6.0 新加的：只砍树，不干农活、不乱捡东西）
- **💾 随时存档（原版存档）**：按 **F5**（或对话里「立即存档」）随时存盘，不用等到睡觉——直接跑游戏原版的 `SaveGame.Save()` 协程，写出的就是和睡觉存档完全一样的存档文件；默认还会把当天开局的存档备份到 `Saves\_AIHireling备份\`。可选打开「只在睡觉时间能存档」：没到点不让存，他会告诉你还差几小时（如「现在才 17:30…要 22:00 才能睡，还差 4 小时 30 分钟」）
- **💀 死亡与涨价**：被怪物打倒下会后在家门口重生，重新雇佣价格上涨（固定或倍率，可调）
- **⚙️ 内置设置菜单**：对着他按 E →「设置」，5 页菜单调工资、行为开关、战斗移动、作息、存档，**不依赖任何其他模组**；另有 GMCM 1.16+ 的完整 8 页（80+ 参数）可选
- **🎨 手绘像素形象**：草帽 + 红领巾小农夫，12 帧四方向行走动画（待机 / 走 1 / 走 2）
- **🔒 旧版兼容**：config.json 与存档数据同旧版完全兼容，无缝升级

## 📦 安装

**环境要求**：星露谷物语 1.6.15+ ｜ SMAPI 4.x

1. 还没装 SMAPI 的话，先去 [smapi.io](https://smapi.io) 下载安装（之后要用 SMAPI 启动游戏，不要直接点 Steam 启动）
2. 下载本仓库 [Releases](../../releases) 里的最新 zip，解压得到一个 `Mods` 文件夹
3. 把 `Mods` 文件夹合并进游戏目录：
   ```
   Steam 版默认：SteamLibrary\steamapps\common\Stardew Valley\
   合并后：Stardew Valley\Mods\AIHireling\
   ```
4. 进游戏！AI 雇工会出现在你的农舍门外

> 配置菜单已内置，**不需要额外装 GenericModConfigMenu**；想要 GMCM 的完整 8 页编辑界面可以另外装 1.16+。

## 🎮 快速上手

1. 进入农场，走到农舍门外的 AI 面前，头顶会显示 `[E] 对话`
2. 按 **E** 对话 → 选择「雇佣」——**第一次雇佣免费**，前 2 天打工也不要钱，之后每天扣日工资（默认 100 G）
3. 对着 AI 按 E →「切换工作模式」选模式，或者用默认的**自动模式**什么都干
4. 想调参数：**走到 AI 面前按 E →「设置（调参数）」**，内置 5 页设置菜单，改完关掉对话即自动保存

**对话菜单操作**：上下左右方向键移动光标 → E / 回车 / 鼠标左键确认 → Esc / 鼠标右键关闭

### 随时存档（v2.1.0）

| 入口 | 说明 |
|------|------|
| 按 **F5** | 默认快捷键，设置页可改成 F6~F9 / K / 无 |
| 对话 →「立即存档」 | 走到 AI 面前按 E |
| `ai_cfg save` | SMAPI 控制台 |

- 走的是**原版存档流程**（`SaveGame.Save()`），存档位、`_old` 备份轮转、文件格式全和睡觉存档一样
- 存档期间世界暂停、输入被吃掉，写完提示「已存档（原版存档）」后继续玩；写盘瞬间会卡顿一两秒（SMAPI 下原版存档是同步写，睡觉存档同样如此）
- **只在单人模式可用**：联机时原版存档要和房客做 ready 同步，硬跑会卡在存档界面，所以直接挡掉并提示
- 剧情/过场/节日中会提示不能存（此时存档会有副作用），过完再存
- 每天第一次随时存档前，把「当天开局存档」复制到 `%AppData%\Roaming\StardewValley\Saves\_AIHireling备份\<存档名>\`，用于兜底

#### 可选：只在睡觉时间能存档（v2.3.0）

设置页「存档与快捷键」→「**只在睡觉时间能存**」（`存档需到睡觉时间`，默认关）。
打开后三个入口都会先看 `Game1.timeOfDay`，没到「回家睡觉时间」（默认 22:00）就拒绝，
AI 会说：

> 现在才 17:30，还没到睡觉的点呢——要 22:00 才能睡，还差 4 小时 30 分钟。等到了我再帮你存。

台词可在 `文本_存档未到点` 改，占位符 `{now}` `{sleep}` `{left}` `{leftmin}`。

## ⚙️ 配置

### 方式一：内置设置菜单（推荐，开箱即用）

走到 AI 面前按 **E** →「**设置（调参数）**」，不需要装任何其他模组：

| 分页 | 可调项 |
|------|--------|
| 工资与雇佣 | 日工资、免费打工天数、重新雇佣基础价、每次死亡涨价、重生等待、预付/欠薪处理 |
| 工作行为开关 | 跟随 / 打怪 / 收获 / 浇水 / 翻地 / 播种 / 采集 / 砍树 / 农场清理 / 挖矿 / 钓鱼 |
| 花费与体力 | **挖矿要镐子 / 挖矿耗体力** / **钓鱼要鱼竿 / 钓鱼耗鱼饵 / 钓鱼耗体力** / 体力上限 |
| 提示与背包 | **提示每天最多 / 之后静默** / 背包满自动找你 / 背包容量（组） |
| 显示效果 | **身体被作物遮挡** / 彩色输出 / 前面加图标 |
| 战斗与移动 | AI 血量、攻击力、移动速度、工作范围、攻击间隔、死亡掉落矿石 |
| 作息时间 | 开始工作时间、回家睡觉时间、夜晚自动回家 |
| 存档与快捷键 | 允许随时存档、**只在睡觉时间能存**、存档快捷键（F5~F9 / K / 无）、存档前自动备份、现在存一次档 |

操作（**任选一种，数值立刻变**）：

- 上下键 / W S 选行
- 左右键 / A D 调数值
- 回车 / E：选中项 +1 步（开关即切换）
- 鼠标左键点某一行：同上
- 右键 / Esc 关闭；关掉对话自动写回 `config.json`

数值显示在【】里，例如 `日工资：【100 G】`。还有「恢复全部默认值」。

**万一界面不灵**（某些键位/输入设备），可在 SMAPI 控制台直接改：

```
ai_cfg               查看当前全部参数
ai_cfg wage 150      日工资改 150
ai_cfg hp 200        血量改 200
ai_cfg clean off     关掉农场清理
ai_cfg save          立刻存一次档（原版存档）
```

可用键名：`wage free price deathprice hp atk atkdelay speed range start sleep clean fight chop mine fish night`

### 方式二：Generic Mod Config Menu（可选，参数更全）

装 **[GMCM 1.16+](https://www.nexusmods.com/stardewvalley/mods/5098)** 后，可在标题界面齿轮按钮 / 游戏内选项菜单底部打开，共 8 个分页覆盖全部 80+ 参数。

> ⚠️ GMCM 必须是 **1.16.0 或更新**。1.11.x 等老版本只支持星露谷物语 1.5，在 1.6 上虽然能加载但**图标不显示**——这就是「找不到扳手图标」的原因。本包已不再附带老版本 GMCM。

### 方式三：直接改 config.json

`Mods/AIHireling/config.json`（中文键名）。改坏了删掉重启就会重新生成默认值。

### 实现要点

- AI **不注册进 `GameLocation.characters`**（避免被游戏日程系统接管），由 `UpdateTicked` 驱动、`RenderedWorld` 手工绘制，移动用 `isCollidingPosition` 碰撞检测
- 跨地图守卫：AI 记录自己所在的 `GameLocation`，不在玩家当前地图时就地待命——不会追进屋、不会穿墙
- 对话 UI 挂在 `Game1.activeClickableMenu` 上阻挡输入，每帧校正菜单挂载状态，保证任何情况下都不会锁死玩家移动
- 随时存档复用原版 `SaveGame.Save()` 协程：置 `Game1.IsSaving`（原版就靠它冻结世界并切到存档画面）→ 挂空白菜单吃输入 → 每帧推一次协程 → 跑完撤标志。协程推进点同时挂在 `UpdateTicked` 与 `Rendered` 上，因为存档时 `Game1.Update` 会提前 return，只靠其一有卡死风险
