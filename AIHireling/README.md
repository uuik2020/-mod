# AI雇工 (AI Hireling) — 《星露谷物语》SMAPI Mod

可雇佣的 AI 雇工 Mod：开局 AI 出现在农舍门外，对话后可免费打工数日，之后按日收费；
能跟随玩家、打怪、收获、浇水、翻地、播种、采集、砍树、挖矿、钓鱼。
AI 死亡后重新雇佣价格上涨，并在家门口重新出现。所有参数支持游戏内 GMCM 配置菜单。

## 游戏内使用

1. 进入农场，AI「小星」站在农舍门外，头顶显示 `[E] 对话`。
2. 按 **E** 打开对话 → 选择「雇佣（500 G）」开始免费打工（默认 2 天）。
3. 免费期结束后每天扣除日工资（默认 100 G，可在配置里改）：
   - 工资早上预付 = 开：每天起床扣当天工资；关：每天睡前结算。
   - 钱不够时默认自动解约回门口待命（可改为赊账继续干）。
4. 对话菜单可：询问状态 / 切换工作模式 / 领取物品 / 设置（调参数）/ 立即存档 / 遣散。

### 随时存档（2.1.0）

不用睡觉也能存档，走的是**游戏原版存档流程**（`SaveGame.Save()` 协程），
写出的文件、存档位、`_old` 备份轮转都和睡觉存档一致。

| 入口 | 说明 |
|------|------|
| **F5** | 默认快捷键，设置页可改 F6~F9 / K / 无 |
| 对话 →「立即存档（原版存档）」 | 靠近 AI 按 E |
| `ai_cfg save` | SMAPI 控制台 |

- 存档期间置 `Game1.IsSaving`（原版就是靠它冻结世界、切到存档画面），挂空白菜单吃输入，
  每帧推一次协程；写完后提示「已存档（原版存档）」并恢复游戏
- 只在单人模式可用（联机时原版存档要和房客 ready 同步，硬跑会卡住）；
  剧情/过场/节日中会拒绝并说明原因
- 每天第一次随时存档前，把当天开局存档复制到 `Saves\_AIHireling备份\<存档名>\`

### 工作模式

| 模式 | 行为 |
|------|------|
| 自动 | 收获→浇水→播种→翻地→采集→砍树→打怪→挖矿→钓鱼，全自动 |
| 跟随 | 只跟着玩家，不干活 |
| 农场 | 只干农活 |
| 战斗 | 主动攻击附近怪物 |
| 农场清理 | 清理农场上的杂草、枯苗、树枝、石头、树桩 |
| 挖矿 | 在矿洞敲矿石 |
| 钓鱼 | 找水边钓鱼；钓什么走原版 `getFish` 判定（地图/季节/天气/水深/钓鱼等级） |
| 待命 | 站在当前/门口不动 |

## GMCM 配置（游戏内）

标题界面或游戏内 → 左下角**扳手图标** → 「AI雇工」，共 8 个分页：

| 分页 | 内容 |
|------|------|
| 主页 | 启用模组 / AI 名字 / 对话按键 + 当前雇佣价摘要 |
| 雇佣与工资 | 雇佣基础价、日工资、免费天数、预付/结算方式、欠薪处理、死亡等待天数 |
| 死亡与涨价 | 涨价模式（固定/倍率）、每次死亡涨价钱/倍率、死亡掉落、死亡次数显示 |
| 工作行为 | 跟随/打怪/收获/浇水/翻地/播种/采集/砍树/挖矿/钓鱼 十个开关 |
| 作息与移动 | 工作时间段、夜晚回家、移动速度、跟随/瞬移距离、工作范围 |
| 战斗 | 血量、攻击力、索敌/攻击距离、攻击间隔、无敌时间 |
| 采集与挖矿 | 可钓鱼类列表（留空 = 游戏鱼表）、可挖矿石列表、钓鱼等待 |
| 对话文本 | 全部对话模板，支持 {name}/{price}/{wage}/{free}/{deaths} 占位符 |

修改后点「保存」写入 `config.json`；也可以直接编辑该文件（键名为中文，与旧版完全兼容，
旧存档的 `config.json` 会被自动读取迁移，无需任何手动转换）。

## 需求实现对照

| 需求 | 实现 |
|------|------|
| AI 开局在玩家房子外面 | 每次进存档自动生成在农舍门外（门下一格） |
| 玩家与 AI 对话 | 靠近按 E 打开对话菜单 |
| 免费打工两天 | `免费打工天数` 默认 2，期内不扣工资；**首次雇佣本身也免费** |
| 之后收费（软件内可改） | 日工资每天结算，GMCM「雇佣与工资」页可调；雇佣费只在遣散/死亡后重新雇佣时收取 |
| 实现玩家全部功能 | 移动/战斗/收获/浇水/翻地/播种/采集/砍树/挖矿/钓鱼 |
| 随玩家移动 | 跟随距离内尾随，超出瞬移送回身边；换地图自动跟随 |
| 死亡后再次雇佣涨价 | `每次死亡涨价` 固定 200 G 或倍率模式，GMCM 可调 |
| 死亡后重新出现在房子附近 | 死亡后第 N 天（默认 0）在家门口重生并提示新价格 |

## 技术说明

- AI 不注册进 `GameLocation.characters`（避免被游戏日程系统接管），由 `UpdateTicked` 驱动、
  `RenderedWorld` 手工绘制，移动用 `isCollidingPosition` 做碰撞检测。
- 收获调用 `Crop.harvest()` 原版逻辑（产物直接进玩家背包），播种消耗玩家背包种子。
- 存档数据键 `aihireling`、配置键名均与 1.0.0 旧版一致，旧存档无缝衔接。
- 随时存档不自己写文件：直接跑 `SaveGame.Save()`；协程推进点同时挂在 `UpdateTicked` 与
  `Rendered`（存档时 `Game1.Update` 会提前 return，只挂一处有卡死风险），60 秒超时兜底。
- GMCM 1.11.2 由 spacechase0 源码针对 net6.0 编译（补了 `StardewValley.Mods` /
  `StardewValley.Network` 两个命名空间 using 以适配 SDV 1.6 API）。
